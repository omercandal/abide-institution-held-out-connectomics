# Decisions required before public release

1. Review the package inventory and confirm public publication under the
   author's GitHub account, repository name `abide-institution-held-out-connectomics`.
2. Choose the license for original code. MIT is a possible code-only choice;
   no MIT license is applied by this release candidate. ABIDE data rights
   remain separate. Confirm permissions for any redistributed aggregate outputs.
3. The release excludes participant-level records, features, predictions,
   checkpoints and source data; review that this is the intended sharing scope.
4. Create the repository and a versioned release. Verify the resulting URL.
5. If a DOI is required, archive the approved release through an authorized
   Zenodo account. No DOI has been reserved or minted in this package.
6. Insert only the verified final repository/release URL or DOI in the
   manuscript and Data Availability statement. Do not cite a guessed URL.
